# ⛔ このブランチからビルドしないでください

**`feature/i18n-editor-auto` は壊れています。**
ここから作った配布物は、エディタの表示が崩れます。

## 何が起きるか

カードに **`{arg0}` `{arg1}`** といった文字がそのまま出ます。
2026-09-04、このブランチから作った Android 版をクローズドテストに上げてしまい、
実機で表示が崩れているのが見つかりました。

## 原因

`scripts/refactor_fragments.ts` が、エディタの JSX を丸ごと翻訳関数の引数に
詰め込む形へ書き換えています（**47箇所**）。

```
tNode(locale, "editor_frag_xxx", { arg1: <JSX/>, arg5: <JSX/>, ... })
```

型チェックは通り、ビルドも成功します。**画面に出して初めて壊れているのが分かります。**

| | JSX を引数に詰めた箇所 | 辞書の `{argN}` |
| --- | --- | --- |
| **main** | **0** | **0** |
| このブランチ | 47 | 38 |

## どうすればいいか

**ビルドは `main` からしてください。** main は正常です（実際の出力で確認済み）。

このブランチを残しているのは、**辞書（1090件の翻訳）が財産だから**です。
やり直すときは:

1. `main` の上で作業する
2. `scripts/apply_translations.ts`（文字列を `t()` に置き換える）は**使ってよい**
3. `scripts/refactor_fragments.ts`（JSX を組み替える）は**使わない**
4. 辞書 `lib/i18n.ts` の 1090 件はここから持ってこられる

⚠️ main とは 14 コミット以上離れており、エディタ画面で正面衝突します。
   合流させようとして一度撤退しました（2026-09-04）。**上書きではなく作り直し。**
