# 配布物の作り方（必読・1ページ）

配布するファイル（`.exe` / `.dmg` / `.appx`）を作る前に、ここだけ読めば足ります。

---

## 鉄則

> ## 配布物は手元で作らない。必ず CI で作る。

このPCは Windows の Application Control ポリシーが `signtool.exe` の起動をブロックします。
そのため NSIS の工程が `spawn UNKNOWN` で落ち、**壊れた実行ファイルが黙って出来上がります。**

タグを打つ（`v*`）か、GitHub の Actions から手動実行してください。
→ [.github/workflows/release.yml](../.github/workflows/release.yml)

## 過去の事故

### 2026-08-10 発覚：v0.1.0 が壊れたまま公開されていた

**何が起きたか**

- `.exe` が素の `electron.exe` より **169,984 バイト小さく**、起動した瞬間に `0x80000003` で即死
- 仮に起動できても Next 16 の cwd 問題で全リクエストが 500

**なぜ気づけなかったか**

**「ダウンロードリンクが 200 を返すか」しか見ていなかった。** ファイルは正しく落ちてくるので確認は通る。
起動しないことは、起動して初めて分かる。

**対策（実施済み）**

CI の最後で **実際にアプリを起動して `http://127.0.0.1:3200/` が 200 を返すか**まで見る。
→ release.yml の「実際に起動して画面が返るか」

### 2026-09-03：検査そのものが罠になっていた

**何が起きたか**

「`.exe` は素の `electron.exe` と**完全に同じサイズ**であること」という検査が入っていた。
アイコンを設定していなかった当時は正しかった。

しかし `build/icon.ico` を追加してアイコンを焼き込むようにした瞬間、
**正常なビルドが必ず「壊れている」と判定される**ようになった。

**なぜ起きたか**

検査が **「その時点の事実」を「永久のルール」として固めていた。**
前提（アイコンが無い）が変わっても、検査は変わらない。誰も気づかない。
気づくのは、次にリリースしようとした日。

**対策（実施済み）**

「同じサイズか」ではなく **「縮んでいないか」** を見る。縮み＝書き換え工程の破損、という不変の性質を見る。

### 2026-09-03：知識が2か所に分かれていて、片方しか読まれなかった

v0.1.0 の事故は、**症状**が `app/page.tsx` に、**原因**が `release.yml` に書かれていた。
どちらも、もう片方を指していなかった。

`page.tsx` だけ読んだ担当が「原因は記録されていない」と判断した。**書いてあったのに。**

**対策**

このファイルに集約した。各所からはここを指すだけにする。**同じ話を2か所に書かない。**

## 検査は何を守っているか

release.yml の各検査を消す前に、何を守っているか確認すること。

| 検査 | 守っているもの |
| --- | --- |
| 実行ファイルが壊れていないか | v0.1.0 の即死（縮んでいたら破損） |
| 画面が同梱されているか | `.next` が抜けた梱包。Electron 本体だけで 180MB あるのでサイズでは気づけない |
| **実際に起動して画面が返るか** | **本丸。** 起動しない／全部 500 を捕まえる唯一の検査 |
| インストーラの出力を確認 | 失敗時に残る数百KBのスタブ |
| Store 用パッケージを検査 | 下記（MSIX 固有）|

### MSIX（`.appx`）で特に大事なもの

**`FileSystemWriteVirtualization` が `disabled` であること。**

これが抜けると Windows が `%APPDATA%` への書き込みを
`%LOCALAPPDATA%\Packages\<PFN>\LocalCache\Roaming` へ**勝手に横流し**する。

GROVE は `.minecraft\mods` に jar を置くので、**保存は成功したように見えるのに Minecraft から見えない。**
読み取りは実体へ抜けるため `existsSync` は true を返し、**エラーが一切出ない。**
`docs/WIN_STRATEGY.md` の負け筋1（作る→マイクラに入る が折れる）そのもの。

設定は [scripts/appx-manifest.js](../scripts/appx-manifest.js) が注入している。
詳細は [docs/MICROSOFT_STORE.md](MICROSOFT_STORE.md)。

## 検査を足す・変えるときのルール

事故のたびに検査は増える。増やし方を間違えると、上の「2026-09-03」を繰り返す。

1. **「いまの事実」ではなく「壊れていない条件」を書く。**
   ✗ サイズが 188,899,840 と一致する / ✗ 素の Electron と同じサイズ
   ○ 素の Electron より縮んでいない

2. **影ではなく本物を確認する。**
   ✗ リンクが 200 を返す ✗ ファイルサイズが正常 ✗ 型チェックが通る
   ○ 起動して画面が出る

3. **その検査が守っている事故を、同じ場所に一行書く。**
   何を守っているか分からない検査は、邪魔になった日に消される。

4. **壊れたものをちゃんと落とせるか試す。**
   通ることだけ確かめた検査は、何も検査していないかもしれない。
