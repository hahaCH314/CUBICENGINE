## 1. 見つけた大きな不具合（利用者が使えなかったもの）

### 10枚のカードがずっと動いていなかった

`runCommandAsync` は**マイクラから削除された古いAPI**。呼ぶとエラーになり、
そのカードだけ黙って動かない。マイクラは何も言わないので、利用者には
「置いたのに何も起きない」としか見えない。

壊れていたカード: アイテム付与 / コマンド実行 / 音 / タイトル / エフェクト /
スコア / キック / **エンティティ召喚** / **パーティクル表示** / フォームのボタン

メッセージ送信だけ動いていたのは `sendMessage` を使っていたから。
**動くカードと動かないカードの差はここだった。**

→ `lib/codegen.ts` の10箇所を `runCommand` に置換。

### その修正が、別のカードを壊した

`beforeEvents.chatSend` の中は**読み取り専用**で、`runCommand` を呼ぶとエラーになる。
つまり「チャットで召喚」のようなカードが新たに壊れた。

自分で「生成コードは常に runTimeout の中で動くので安全」とコメントを書いたが、
**実際そうしていたのは ev_join だけだった。** 事実と違うコメントで自分を欺いた。

→ `ev_chat` は `event.cancel` だけその場でやり、処理は `system.run` で次のティックへ逃がす。

### お手本(プリセット)の設定値が全部無視されていた

`lib/presetTemplates.ts` のフィールドIDが `data/templates.ts` の定義と食い違っていた。

```
書いてあった: "sound"  "cnt"
正しい名前  : "snd"    "count"
```

「爆発ニワトリ」でダイヤ16個が1個になり、爆発音も鳴らなかった。
**初めて触る人が最初に開くのがお手本なので、これが一番まずい。**

⚠️ **プリセットを足すときは data/templates.ts の `fields[].id` と必ず突き合わせること。**
綴りが違っても型は通り、実行時に黙って無視されるので気づけない。
