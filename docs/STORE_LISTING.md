## 説明（Description）

```
コードを書かずに、マインクラフト（Java版）のMODを作れる開発スタジオです。

ブロックを置くように部品を組み合わせるだけで、オリジナルの武器・ブロック・
モブ・アイテムが作れます。プログラミングの知識は要りません。

作ったものは .jar ファイルとして書き出され、そのままMODとして遊べます。


■ こんなことができます

・自分だけの武器やブロックを作る
・オリジナルのモブを作って、世界に登場させる
・「〇〇したら△△する」を、目で見て組み立てる
・作ったMODを、そのままフォルダへ入れて遊ぶ


■ 対応しているバージョン

・Forge 1.20.1
・NeoForge 1.21.1

MODのビルドには Java（JDK）のインストールが必要です。
必要なものが揃っているかはアプリが確認して案内します。


■ 大切にしていること

CUBICENGINE は、中学生の作者が「自分が欲しかったもの」として作りはじめた
ツールです。すべての機能が無料で、広告もありません。

「作りたい」と思った瞬間から、実際に動くMODができるまでを、
できるだけ短く、できるだけ楽しくすることを目指しています。


■ ご利用にあたって

・本アプリでMODを作るには、別途 Minecraft Java Edition が必要です
  （本アプリには含まれていません）
・作成したMODの利用は自己責任でお願いします
```

## Description

```
Make your own Minecraft: Java Edition mods without writing a single line of code.

Snap parts together like building blocks and create original weapons, blocks,
mobs and items. No programming knowledge needed.

What you make is exported as a .jar file — ready to drop in and play.


■ What you can do

・Build your own weapons and blocks
・Create original mobs and bring them into your world
・Put together "when this happens, do that" visually
・Send finished mods straight to your mods folder


■ Supported versions

・Forge 1.20.1
・NeoForge 1.21.1

Building a mod requires Java (JDK) to be installed.
The app checks what you need and walks you through it.


■ What we care about

CUBICENGINE started as something a middle school student wanted for himself and
could not find. Every feature is free, and there are no ads.

The goal is to make the distance between "I want to make this" and "it works in
my game" as short — and as fun — as possible.


■ Before you start

・You need Minecraft: Java Edition to use the mods you create.
  It is not included with this app.
・Use the mods you create at your own risk.


---
NOT AN OFFICIAL MINECRAFT PRODUCT.
NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.
```
